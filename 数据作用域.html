    6. 数据作用域

    Web 应用程序同时为许多用户提供服务，每个用户还会发出大量请求。因此，数据可以在多个层级上共享，这些层级称为数据的作用域：

    • 应用程序作用域：数据在服务器的整个生命周期内由所有用户共享（例如医生列表）；
    • 请求作用域：数据仅在单个请求期间存在（视图的模型，以及为该请求所识别出的已登录用户）；
    • 客户端作用域：数据专属于某个用户，并且必须在一个请求到下一个请求之间保持（所选语言、已登录用户）。

    对于最后这种作用域，Web 应用程序长期以来使用由服务器维护的会话：即为每个浏览器专设的一块内存，通过标识 Cookie 来识别（[JSESSIONID] 用于 [Java]，[PHPSESSID] 用于 [PHP]）。[Flask] 的会话则不同：正如我们在示例 20 中看到的，它存储在客户端的已签名 Cookie 中。服务器在同一用户的两次请求之间不存储任何东西：这称为无状态。例如，这使得可以在负载均衡器后面运行多个相同的服务器：其中任何一个都可以处理任何请求。代价是 Cookie 受用户控制；用户可以读取它，并尝试修改它。因此，这里只存放非敏感数据，并且——如果数据必须可信——由服务器对其签名，服务器随后便能检测到任何修改：[Flask] 的会话和身份验证令牌就是这种情况（见身份验证一章）。

    在 [Flask] 中，每种作用域都有自己的容器：

    作用域
    载体
    生命周期
    应用程序
    启动时创建的对象，存储在 [app.extensions] 中，并通过 [current_app] 获取（示例 06）
    整个服务器生命周期，由所有请求共享
    请求
    对象 [g]，以及对象 [request] 本身（示例 16）
    处理请求期间
    会话
    对象 [session]，一个存储在已签名 Cookie 中的字典
    直到浏览器关闭（默认情况）
    客户端
    由 [set_cookie] 设置的标准 Cookie（示例 22）
    由 [max_age] 设定的时长

    对象 [current_app]、[g]、[request] 和 [session] 都是从包 [flask] 中导入的。它们是代理 （示例 05）：在请求期间，每个代理都指向该请求（或处理该请求的应用程序）的对象。

    # services/counter.py：一个共享计数器，以及一次请求的信息
from itertools import count
from threading import Lock


# APPLICATION 作用域：唯一的实例（见 app.py）
class CounterService:

    def __init__(self):
        self._total = 0
        # 多个请求可能同时运行：锁保证
        # 两次同时进行的递增不会丢失
        self._lock = Lock()

    def increment(self) -> int:
        with self._lock:
            self._total += 1
            return self._total


# REQUEST 作用域：每个请求一个实例（见 app.py，start 函数）
class RequestInfo:

    # 由所有实例共享的计数器（类属性）；
    # next(...) 是原子的：两个线程绝不会得到同一个数字
    _instances = count(1)

    def __init__(self, start: str):
        self.number = next(RequestInfo._instances)
        self.start = start
    • 第 7–18 行：一个访问计数器，具有应用程序作用域：只有一个对象，由所有请求共享。与示例 20 中的任务列表一样，由一把锁保护递增操作：[self._total += 1] 语句不是原子的 （它先读取值，再递增，然后写回），两个线程同时执行它可能会读到相同的值——导致丢失一次访问；
    • 第 22–30 行：请求作用域的信息：每个请求一个对象，包含一个编号和请求的时间。编号来自所有实例共享的计数器：标准模块 [count(1)] 的 [itertools] 是一个迭代器 ，每次调用 [next] 时依次产生 1、2、3……这是一个类属性 （在类级别而不是构造函数中声明）：它由所有实例共享。

    # app.py：示例 23 的应用
from datetime import datetime
from pathlib import Path

from flask import Blueprint, Flask, g

from controllers.scopes import scopes
from services.counter import CounterService, RequestInfo

BOOTSTRAP = Path(__file__).resolve().parent.parent / "common" / "bootstrap"


def create_app():
    app = Flask(__name__)
    app.jinja_env.trim_blocks = True
    app.jinja_env.lstrip_blocks = True
    # 为会话 Cookie 签名的密钥（SESSION 作用域）
    app.config["SECRET_KEY"] = "a-secret-key-for-example-23"
    # APPLICATION 作用域：单一对象，在启动时创建，由所有用户的
    # 所有请求共享
    app.extensions["counter"] = CounterService()
    app.register_blueprint(Blueprint("bootstrap", __name__, static_folder=BOOTSTRAP,
                                     static_url_path="/bootstrap"))
    app.register_blueprint(scopes)

    # REQUEST 作用域：g 对象随每个请求而生，随请求而灭。这个
    # 在动作之前执行的函数，在其中存入一个对象，动作和
    # 视图会在本次请求中再次找到它
    @app.before_request
    def start():
        g.info = RequestInfo(datetime.now().strftime("%H:%M:%S.%f")[:-3])

    return app


if __name__ == "__main__":
    create_app().run(port=5000, debug=True)
    • 第 18 行：用于对会话 Cookie 签名的密钥；
    • 第 21 行：应用程序作用域的对象；
    • 第 29–31 行：在每个请求之前，一个 [RequestInfo] 对象被存储在 [g] 中。动作和视图会获取它，但只限于本次请求期间。[strftime("%H:%M:%S.%f")] 把时间格式化为带微秒的形式（[%f]，六位数字）；[[:-3]] 去掉字符串的最后三个字符，只留下毫秒。

    # controllers/scopes.py：四种数据作用域
from flask import Blueprint, current_app, g, make_response, render_template, request, session

scopes = Blueprint("scopes", __name__)


@scopes.get("/")
def display():
    # APPLICATION：共享计数器
    total = current_app.extensions["counter"].increment()
    # SESSION：本浏览器专属的字典，Flask 将其存放在
    # 签名的 Cookie（session）中；它持续到浏览器关闭为止
    session["visits"] = session.get("visits", 0) + 1
    # CLIENT：由浏览器保存在普通 Cookie 中的一份数据，
    # 每次请求都会回传给服务器
    my_visits = to_integer(request.cookies.get("myVisits")) + 1
    response = make_response(render_template(
        "scopes/scopes.html", total=total, instance=g.info.number,
        session_visits=session["visits"], my_visits=my_visits))
    response.set_cookie("myVisits", str(my_visits), httponly=True, samesite="Lax")
    return response


# "41" -> 41；None 或 "abc" -> 0
def to_integer(text: str | None) -> int:
    try:
        return int(text)
    except (TypeError, ValueError):
        return 0
    • 第 10 行：应用程序作用域。[current_app] 指向正在处理当前请求的应用程序；
    • 第 13 行：会话作用域。[session] 像字典一样使用：[session.get("visits", 0)] 返回该键的值，如果该键不存在则返回 0。当动作修改会话时，[Flask] 会在响应中附带发送一个新的 Cookie [session]，其中包含已签名的字典；
    • 第 16 行：客户端作用域，使用一个普通 Cookie [myVisits]，读取自 [request.cookies]。它的值是浏览器提供的字符串，因此可能缺失或无效；函数 [to_integer] 在这两种情况下都返回 0；
    • 第 17–20 行：要设置 Cookie，需要响应对象：[make_response] 用视图生成的页面构造它（示例 05），然后 [set_cookie] 向其添加头部 [Set-Cookie]。如果没有 [max_age]，Cookie 会持续到浏览器关闭（它是浏览器所定义的“会话”Cookie）；
    • 第 18 行：请求作用域：存储在 [g] 中的对象，由函数 [start] 存入。
