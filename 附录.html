    13. 附录

    13.1. 安装 Python

    [Python] 可从 python.org/downloads 下载。示例和案例研究需要版本 3.12 或更高；它们已在 3.13 版本上测试过。

    在 [Windows] 中，安装程序的第一个界面会显示“Add python.exe to PATH”复选框：必须勾选它。这样 [python] 命令就可以在所有终端中使用。安装程序还会安装 [py] 启动器，当安装了多个版本时，可以用它选择版本（[py -3.13]）。你也可以使用包管理器 [winget]：

    1
    winget install Python.Python.3.13

    对于 [macOS]，请使用同一页面上的 [.pkg] 安装程序，或使用 [Homebrew] 包管理器（[brew install python@3.13]）。在 [Linux] 下，[Python] 通常已经安装；请检查其版本，必要时安装用于创建虚拟环境的 [venv] 模块（在 [Ubuntu] 下：[sudo apt install python3-venv]）。在 [macOS] 和 [Linux] 下，该命令通常称为 [python3] （以及 [pip3]）：创建虚拟环境时使用的就是这个命令。环境激活之后，[python] 和 [pip] 指的就是环境内的那两个命令。

    在新的控制台中验证安装（[PowerShell]、命令提示符或终端）：

    1
    python --version

    它应显示等于或高于 3.12 的版本号（例如 [Python 3.13.7]）。对于更旧的版本，案例研究会因语法错误而在启动时停止（参见“常见问题”）。

    13.2. 虚拟环境和 pip

    虚拟环境 是一个文件夹（此处为 [.venv]），其中包含 [Python] 解释器的一个副本以及项目的库。这样，每个项目都有自己的一套，版本也适合自己。[examples] 文件夹有它自己的环境，由全部 28 个示例共享；案例研究则有它自己的环境。

    常用命令，在 [Windows] 下（在 [Linux] 和 [macOS] 下，用 [source .venv/bin/activate] 来激活）：

    1
2
3
4
5
    python -m venv .venv               # 创建环境（只需一次）
.venv\Scripts\activate             # 激活环境（在每个新终端中）
pip install -r requirements.txt    # 安装项目的库
pip list                           # 已安装的库
deactivate                         # 停用环境

    [pip] 从 [PyPI] （pypi.org）仓库下载库：安装期间需要连接互联网。如果你位于企业代理之后，请使用 [--proxy] 选项在 [pip] 中指定代理。虚拟环境不能从一台机器复制到另一台机器（它包含绝对路径）：必须使用 [requirements.txt] 文件重新创建它。这就是课程资料中不包含 [.venv] 文件夹的原因。

    13.3. 安装 Visual Studio Code

    从 [Visual Studio Code] 下载 code.visualstudio.com。添加 Microsoft 的 Python 扩展（“视图”菜单 / “扩展”，然后搜索“Python”）：这也会安装 [Pylance] （自动补全、类型检查、错误报告）和 Python Debugger。像 Better Jinja 这样的扩展可以为 [Jinja2] 视图（包含 {{ }} 和 {% %} 标签的 HTML 文件）添加语法高亮。

    打开 [examples] 文件夹或案例研究文件夹（“文件”菜单 / “打开文件夹”）。扩展会检测到 [.venv] 虚拟环境并提示你使用它：接受该提示（也可以用 Python 命令“Select Interpreter”来选择，快捷键 [Ctrl-Shift-P]）。内置终端（“终端”菜单 / “新建终端”）随后会自动激活该环境，使你无需离开编辑器就能运行应用程序。[F5] 键（在 [app.py] 文件中）会在调试器的控制下运行应用程序（参见“开发模式”）。

    13.4. 使用 Laragon 安装 MySQL

    [Laragon] （laragon.org）会安装一个开箱-即用的 [MySQL] 服务器（或 [MariaDB]），以及 [HeidiSQL] 管理工具。安装之后：

    • “Start All”按钮会在 3306 端口上启动 [MySQL] 服务器；
    • 用户 [root] 没有密码：这些是示例 28（[DATABASE_URL]）和案例研究（[DB_USER]、[DB_PASSWORD]）中的默认值；
    • “Database”按钮会打开 [HeidiSQL]，在其中通过“文件”菜单 / “运行 SQL 文件”来运行脚本 [dbpersons.sql] （示例 28）和 [dbrdvmedecins2.sql] （案例研究）。

    对于 [Linux] 或 [macOS]，请使用系统的包管理器安装 [MySQL] 或 [MariaDB] ，并使用命令行客户端 [mysql] 运行脚本。[PyMySQL] 驱动无需任何配置就能同时配合这两者使用。在 [Linux] 下，[root] 账户（对于 [MariaDB] ）通常被配置为只能通过系统账户 [root] 登录（[sudo mysql]）：在这种情况下，需要为应用程序创建一个用户，并在它们的配置中指定该用户：

    1
    sudo mysql -e "CREATE USER 'course'@'localhost' IDENTIFIED BY 'course'; GRANT ALL ON *.* TO 'course'@'localhost';"

    13.5. 安装 curl

    [curl] 包含在 [Windows] 10 和 11、[macOS] 以及大多数 [Linux] 发行版中。在 [PowerShell] 中，必须输入 [curl.exe]，而不是 [curl]：在较旧版本的 [PowerShell] 中，[curl] 是另一个命令（[Invoke-WebRequest]）的别名，它的选项不同。在 [Windows] 的命令提示符（[cmd]）中，JSON 字符串的引号要写成 [\"] （示例 11），并且包含 [&] 的 URL 必须用双引号括起来。
